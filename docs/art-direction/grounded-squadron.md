# Grounded Squadron

Six local flightless-bird pilots: Penguin, Kiwi, Ostrich, Emu, Cassowary, and Kākāpō. Stylized cartoon anatomy and wearable jetpacks; identical gameplay collision geometry to other pilots. Generated from the Cocoa Comet style reference using the built-in image tool. Original art retained in assets/polished; shipping transparent 720px WebP sprites in assets/optimized.

Each nozzle has calibrated live exhaust, flicker, boost intensity, and reduced-motion support. Existing preview hover and flight pitch provide movement.
