# Local arcade expansion

Nitro 10 uses a new open-cockpit sprite at assets/polished/nitro10-v3.webp. The existing dog, rocket, number and palette are retained; glass canopy removed.

Game-over sequence uses assets/optimized/friendly-cloud.webp, selected pilot artwork and a CSS parachute. The short sequence is skippable and static for reduced motion. Cap Dash is a 60-second collection mode with x1–x5 combos, collision recovery, pause support and separate device-local records. Aircraft are stylized interpretations, not scale replicas.
